# Osmos Brand Guidelines

## Brand essence
Osmos is the shared-context layer that lets project knowledge move across people and AI agents without manual copy-paste.

The brand should feel:
- calm
- intelligent
- premium
- technically credible
- fluid without being decorative
- human without being soft or playful

Avoid generic AI aesthetics: glowing brains, node clouds, neon-on-black cyberpunk, rainbow gradients everywhere, robot imagery, and overly organic biotech visuals.

## Positioning
**Core line:** Different people. Different agents. Same project understanding.

**Short descriptor:** Shared context for AI teams.

**Long descriptor:** Osmos keeps humans and AI agents working from the same continuously updated project knowledge across models, accounts, sessions, and tools.

## Logo concept
The Osmos symbol combines:
- a **white horizontal connective axis** behind the mark, representing the persistent shared project layer;
- five vertical/curved streams representing independent agents, humans, tools, and sources;
- a violet-to-cyan progression across the streams, representing context flowing through the system.

The structure should always remain simple enough to read at small sizes.

### Logo rules
- Preserve original proportions.
- Maintain generous clear space: at least 0.5x the symbol width around the full lockup when possible.
- Do not rotate, skew, add shadows, bevels, textures, or extra glow.
- Do not change individual stream colors outside the approved palette.
- Do not make the horizontal axis anything other than white on dark backgrounds or near-black on light backgrounds.
- Use the full wordmark where space permits; use the symbol alone for favicon/app/social-avatar cases.
- A monochrome mark is acceptable when color reproduction is constrained.

## Color system
### Core neutrals
- Ink 950: `#0B111B` — primary dark background
- Ink 900: `#111827` — raised dark surface
- Ink 800: `#162033` — elevated card / border-adjacent surface
- Mineral White: `#F7FAFF` — primary light text and light surface
- Mist: `#A9B3C5` — secondary text on dark backgrounds

### Flow palette
Use these as discrete logo streams and as the stops in the Osmos Flow gradient:
- Violet 500: `#B02EFF`
- Violet 400: `#8A4DFF`
- Indigo 400: `#6666FF`
- Blue 400: `#3E8CFF`
- Aqua 400: `#30C4F4`

### Primary gradient
`linear-gradient(90deg, #B02EFF 0%, #8A4DFF 25%, #6666FF 50%, #3E8CFF 75%, #30C4F4 100%)`

The gradient is a brand signature, not a default fill. Prefer neutral layouts with strategically placed flow color.

### Accessibility note
On Ink 950, Mineral White, Mist, Blue 400, and Aqua 400 have strong text contrast. Violet-family colors should primarily be used for decoration, icons, graph marks, focus accents, gradients, and large text rather than small body copy.

## Typography
### Primary family: Inter
Use **Inter** for product UI, website copy, documentation, decks, and most marketing assets. It is neutral, highly readable, modern, and widely available to web and design tooling.

Recommended weights:
- 400 Regular: body
- 500 Medium: labels and navigation
- 600 Semibold: headings, CTA labels
- 700 Bold: rare emphasis

### Display treatment
Use Inter with tight but restrained tracking for large display headlines. Avoid ultra-heavy 800/900 weights.

Suggested typography scale:
- Hero: 64–80px desktop / 44–52px mobile, 600, line-height 0.98–1.06
- H1: 48–64px, 600
- H2: 32–44px, 600
- H3: 22–28px, 600
- Body large: 18–20px, 400
- Body: 16px, 400
- Small: 13–14px, 400/500
- Mono: `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`

### Wordmark treatment
The Osmos wordmark should remain clean, geometric, and relatively light. Do not set the wordmark in a heavy display face.

## Layout and spacing
Use an 8px base spacing rhythm.

Typical spacing tokens:
- 4, 8, 12, 16, 24, 32, 48, 64, 96, 128

Marketing pages should feel spacious. Product UI can be denser, but should still preserve hierarchy and clear grouping.

### Corners
- Small controls: 8px
- Inputs / compact cards: 10–12px
- Marketing cards: 16–20px
- Pills: 999px

Avoid excessive rounding. Osmos should feel precise, not bubbly.

## Visual language
The core visual metaphor is **knowledge moving across a selective boundary**.

Use:
- parallel streams
- gentle convergence/divergence
- thin connective axes
- bounded flow paths
- soft directional gradients
- revision/activity trails
- quiet grids and topology-like diagrams

Avoid:
- literal water droplets
- cells/membranes as the dominant visual
- flowers/petals
- neural-network node webs
- circuit-board clichés
- infinity symbols
- random glowing blobs

## Motion language
Motion should communicate transfer and synchronization.

Preferred interactions:
- a pulse travels across the white connective axis;
- one stream activates, crosses the axis, and causes another stream to illuminate;
- context cards subtly slide from source agent toward shared layer, then resolve at destination;
- revisions appear as calm incremental ticks, not dramatic explosions.

Timing:
- micro interaction: 140–220ms
- standard transition: 220–360ms
- hero/demo flow: 600–1200ms

Use ease-out or smooth cubic-bezier curves. Avoid springy/bouncy animation.

## Product UI
Primary UI should be dark-first but fully support a light theme.

### Dark theme
- page: `#0B111B`
- surface: `#111827`
- elevated surface: `#162033`
- primary text: `#F7FAFF`
- secondary text: `#A9B3C5`
- border: `rgba(169,179,197,0.16)`
- primary action: use Blue 400 or a restrained blue/indigo fill
- flow gradient: reserved for selected states, provenance trails, handoff visualization, and hero moments

### Light theme
- page: `#F7FAFF`
- surface: `#FFFFFF`
- elevated surface: `#F1F5FA`
- primary text: `#0B111B`
- secondary text: `#5F6B7B`
- border: `rgba(11,17,27,0.12)`

## Marketing imagery
Osmos marketing should emphasize the cross-agent handoff rather than abstract AI power.

Strong example:
1. Agent A learns a decision.
2. Osmos records the durable project knowledge.
3. Agent B, in another account/model, automatically receives and uses it.

Visualize this with real product screenshots, clean diagrams, and the flow palette.

## Website art direction
Recommended homepage structure:
1. Minimal dark hero
2. Primary line: “Different people. Different agents. Same project understanding.”
3. Short descriptor + CTA
4. Animated Osmos Moment showing a handoff
5. Supported agent/model logos shown quietly in monochrome
6. Product pillars: shared context, private/shared scopes, provenance, model independence
7. Technical credibility: MCP/API/GitHub/dev workflow
8. Social proof / founding teams
9. Final CTA

Do not make the homepage a giant gradient canvas. Let the logo and handoff visualization provide color.

## Voice
Osmos voice is direct, technically literate, calm, and concise.

Prefer:
- “Share project knowledge across agents.”
- “Keep every agent working from the same project understanding.”
- “See where context came from.”
- “Private when it should be. Shared when it should be.”

Avoid:
- “revolutionary”
- “magical AI”
- “supercharge”
- “10x everything”
- “second brain”
- “AI brain”
- “memory layer” as the primary category

## The Osmos Moment
The signature product/brand event is a **cross-agent context handoff**.

Definition:
> Agent A produces durable project knowledge → Osmos stores it → Agent B retrieves it → Agent B’s response or action materially changes.

This should become a recognizable product animation, marketing demo, social share card, and analytics event.

Suggested share copy:
**“Claude just used context learned by my teammate’s ChatGPT.”**

## Social / launch visuals
Use:
- Ink 950 background
- Mineral White type
- one focused gradient flow graphic
- large simple headline
- generous whitespace
- real product/UI crop when available

Avoid dense feature grids and generic AI stock imagery.

## Implementation principle
The brand identity is mostly neutral. Color appears when **knowledge moves**.

That single rule should guide the website, product, motion, decks, and social assets.
