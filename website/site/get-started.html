Get Osmos

Osmos is one Python service that you run. There is no hosted version today — you deploy it for your team, or run it locally to see it work first.

Recommended

Run it for your team

Osmos is multiplayer by nature — the value only appears once two agents share a project. This is the path that produces a real handoff.

1

Deploy the service

The repository ships a Render blueprint (render.yaml) that provisions PostgreSQL and the web service together. Any host that runs a Python process and a Postgres database works equally well.

required environment 
SAC_AUTH_MODE=auth
DATABASE_URL=postgresql://...
SAC_BOOTSTRAP_ADMIN_EMAIL=you@example.com
SAC_BOOTSTRAP_ADMIN_PASSWORD=...
SAC_ALLOWED_REDIRECT_HOSTS=claude.ai,claude.com,chatgpt.com,openai.com
SAC_CIMD_ALLOWED_HOSTS=chatgpt.com,openai.com

SAC_AUTH_MODE=auth is required for any deployment reachable from the internet. Record the public URL — everything below refers to it as your base URL.

2

Create the project and add your teammate

Run these against the deployed database — from your host's shell, or locally with DATABASE_URL pointing at it.

shell 
python -m app.auth.cli add-project --owner you@example.com --name "Our Project"

python -m app.auth.cli add-user --email teammate@example.com --password "..." --name "Teammate"

python -m app.auth.cli add-member --project <project-id> --email teammate@example.com --role member

Anyone who belongs to exactly one project never has to name it in a tool call — Osmos resolves it from their membership.

3

Connect Claude

Settings → Connectors → Add custom connector. Give it a name and the URL <your-base-url>/mcp. Claude registers itself, opens the Osmos sign-in, and asks you to approve scopes. Enable the connector in your project and set the sac_* tools to “Allow always”.

4

Connect ChatGPT

Settings → Apps → Advanced → Developer mode, then add a custom connector with the same /mcp URL and OAuth authentication. If developer mode isn't available on your plan, build a Custom GPT and import <your-base-url>/openapi.json as an Action instead.

5

Tell the agents to use it

Paste this into each assistant's project instructions. It's the whole configuration — after this, nobody thinks about Osmos again.

project instructions 
Osmos is always-on shared project memory. While this connector is
enabled: at the START of every turn call sac_sync_context with my
request as `task` (and a short local_context_delta summarising durable
knowledge from your previous turn). Use the returned context as project
memory. Before your final answer, call sac_remember_shared for any
reusable decision, requirement, constraint, finding or result, or
sac_remember_private for your own notes. Never publish secrets or
personal data. Do this automatically without asking.
The moment it clicks

Your first handoff

Two accounts, two different assistants, no copy-paste between them. This takes about a minute and is the fastest way to know it's working.

1

Say something durable in ChatGPT

“We're using Supabase Auth with passkeys.” The agent publishes it. Confirm it landed in /console — you should see the memory, a revision bump, and an audit row.

2

Ask Claude something related

From the second account: “Implement Windows auth.” It syncs, receives the decision with no prompting from you, and works from it.

3

Check that private stays private

Write a private memory from one account and confirm the other never receives it. This path is covered by the test suite as well.

4

Revoke a client

Revoke the connection in /auth/connections. The next call from that client fails until it is authorised again.

Try it first

Run it on your machine

Python 3.13 and nine dependencies. It starts on SQLite with no configuration, so you can see the mechanics before you deploy anything.

shell 
git clone https://github.com/SamEthanMathew/Shared-Agent-Context
cd Shared-Agent-Context
pip install -r requirements.txt
uvicorn app.main:app

Then point any local MCP client at http://127.0.0.1:8000/mcp.

!

Local mode is unauthenticated. SAC_AUTH_MODE defaults to dev, which identifies the caller from an actor email supplied by the client — spoofable by design, and fine on your own machine. Never expose a dev-mode instance to the internet. Set SAC_AUTH_MODE=auth for anything reachable.
