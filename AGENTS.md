# Repository Guidance for AI Coding Agents

When working on product UI, websites, documentation UI, launch pages, marketing pages, social graphics, or any other user-facing Osmos surface, **read the website brand system before making design decisions**:

1. `website/AI_BRAND_CONTEXT.md`
2. `website/BRAND_GUIDELINES.md`
3. `website/tokens.json`
4. `website/osmos.css`
5. `website/assets/`

The core design rule is:

> **The interface is calm and neutral; color appears when knowledge moves.**

Do not substitute generic AI styling, random gradients, robot/brain imagery, or unrelated design systems for the Osmos brand.

The older `branding/` directory is retained for continuity, but new website and marketing implementation should treat `website/` as the primary source of truth.

For backend-only work, these brand files are not relevant unless the change exposes user-facing text or UI.
