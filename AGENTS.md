# Repository Guidance for AI Coding Agents

When working on product UI, websites, documentation UI, launch pages, marketing pages, social graphics, or any other user-facing Osmos surface, **read the brand system before making design decisions**:

1. `branding/AI_BRAND_CONTEXT.md`
2. `branding/BRAND_GUIDELINES.md`
3. `branding/tokens.json`
4. `branding/osmos.css`
5. `branding/assets/`

The core design rule is:

> **The interface is calm and neutral; color appears when knowledge moves.**

Do not substitute generic AI styling, random gradients, robot/brain imagery, or unrelated design systems for the Osmos brand.

For backend-only work, these brand files are not relevant unless the change exposes user-facing text or UI.
